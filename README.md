A deterministic Python program that writes one sentence — at most 200 characters — pitching a bizarre startup idea that sounds like a joke until the business logic lands, to /output/entry.txt. The pitch rents retired racehorses to burned-out offices as therapists: startups pay $400 an hour because a 500-kilo animal whose only agenda is carrots is the one meeting nobody can ruin.

## Run it

```sh
python3 main.py
```
